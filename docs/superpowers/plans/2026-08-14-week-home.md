# 주간 캘린더 홈 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** `/dashboard`를 월–일 주간 보드로 바꾸고, 습관·계획·그 주 커밋 기반 블로그/LinkedIn/X 초안 복사를 한 화면에 넣는다.

**Architecture:** 순수 `WeekDates`(Asia/Seoul, 월요일 시작) + `WeekService`가 습관 시드/집계와 주간 보드 DTO를 만든다. 블로그 주간 생성은 기존 `BlogPost`에 소셜 필드와 `weekStart`를 붙여 Gemini JSON을 저장한다. 프론트는 대시보드를 레일+7열+초안 카드로 교체한다.

**Tech Stack:** Kotlin/Spring Boot 3.3, JPA, React/TypeScript, 기존 GeminiClient.

**Spec:** `docs/superpowers/specs/2026-08-14-week-home-design.md`

## Global Constraints

- 타임존은 `Asia/Seoul`, 주는 월요일 시작. `weekStart`가 월요일이 아니면 400.
- LinkedIn/X 실제 발행 API는 넣지 않는다. 복사만.
- 기존 `POST /api/blog-posts/generate`는 삭제한다.
- 사용자 규칙상 커밋은 하지 않는다.
- 스펙의 주 경계·습관 재계산은 단위테스트로 고정한다.
